# Grok Budget Controller

Контроль расходов Grok (xAI) для всех 8 ботов AI Trading Desk:

1. **Стоп-кран.** Одной командой останавливает всю команду или отдельного бота.
2. **Недельный дашборд.** Показывает, какую долю бюджета в процентах забирает каждый бот и каждая команда.
3. **Анализ и очистка.** Находит расходы без пользы: ошибки API, пустые ответы, повторные одинаковые запросы, ответы, помеченные как бесполезные, раздутые промпты. Отключает ботов, которые ничего не приносят.
4. **Автоматическое распределение бюджета.** Делит недельный бюджет между ботами так, чтобы денег хватило на 8 дней. Резерв при этом не раздаётся: он остаётся под другие настройки.

Зависимостей нет, нужен только Python 3.11+.

## Быстрый старт

```bash
export XAI_API_KEY=...                 # ключ только через переменную окружения
python -m grok_budget stop             # 1. остановить всю команду
python -m grok_budget dashboard        # 2. посмотреть, кто сколько тратит
python -m grok_budget analyze          # 3. что бесполезно и почему
python -m grok_budget cleanup          #    план очистки (пробный прогон)
python -m grok_budget cleanup --apply  #    применить
python -m grok_budget allocate         # 4. рассчитать и сохранить лимиты
python -m grok_budget resume           # 5. запустить команду с новыми лимитами
```

Раз в неделю (например, по cron): `python -m grok_budget rebalance --auto-cleanup`.

## Подключение ботов (обязательно)

Стоп-кран, лимиты и дашборд работают **только для запросов через `GrokClient`**. Бот, который
обращается к API xAI напрямую, контроль не видит.

```python
from grok_budget import GrokClient, BotStopped, BudgetExceeded

grok = GrokClient("technical_analyst")        # имя из grok_config.toml

while not grok.should_stop():                 # проверка стоп-крана в главном цикле
    try:
        answer = grok.chat([{"role": "user", "content": prompt}])
    except BotStopped:
        break                                 # команду остановили
    except BudgetExceeded:
        sleep_until_tomorrow()                # дневной/недельный лимит исчерпан
        continue
    grok.mark(useful=is_useful(answer))       # необязательно, но сильно улучшает анализ
```

Если у вас есть экспорт расходов из консоли xAI, его можно загрузить:
`python -m grok_budget import-csv usage.csv`. Колонки: `ts,bot,model,prompt_tokens,completion_tokens[,cost_usd,status,outcome]`.

## Как распределяется бюджет

| Шаг | Что происходит |
|---|---|
| Резерв | `weekly_budget_usd × reserve_percent` ботам не раздаётся (по умолчанию 15%) |
| Вес бота | `(50% приоритет + 50% фактическая потребность за неделю) × эффективность` |
| Эффективность | `1 − доля потерь`, но не меньше 0.2 |
| Границы | доля каждого бота зажата в `[min_share, max_share]`; остаток перераспределяется |
| Темп | дневной лимит = недельный лимит / `plan_days` (8), чтобы хватило на неделю с запасом |
| Отключённые | вердикт DISABLE, пауза или отключение дают бюджет 0 |

`enforcement = "hard"` блокирует бота, когда его лимит исчерпан; `"soft"` только предупреждает.
Risk Manager отмечен `protected = true`, поэтому автоматически он не отключается никогда.

## Вердикты анализа

| Вердикт | Значение |
|---|---|
| OK | всё нормально |
| IDLE | за неделю ни одного вызова |
| TRIM | средний промпт больше `long_prompt_tokens`: сократить контекст |
| CACHE | много повторных одинаковых запросов: включить кэш или увеличить окно |
| REDUCE | потери ≥ 30% или доля выше `max_share`: лимит урезается |
| DISABLE | потери ≥ 80% и ни одного полезного ответа: бот отключается после `cleanup --apply` |

Вернуть отключённого бота: `python -m grok_budget unpause <bot>`.

## Что удаляет `cleanup`

- Отключает ботов с вердиктом DISABLE (кроме защищённых).
- Удаляет сырые записи старше `retention_days`. Перед удалением итоги по неделям сохраняются в `weekly_summary`.
- Удаляет устаревший кэш ответов.

Без `--apply` ничего не удаляется.

## Файлы

- `grok_config.toml`: бюджет, резерв, цены моделей, боты, приоритеты, лимиты. **Цены сверяйте с консолью xAI.**
- `grok_state/`: лог расходов (SQLite), стоп-кран, лимиты. Папка в `.gitignore`.
- `reports/weekly_dashboard.html`: дашборд.
- Тесты: `python -m unittest discover -s tests`.
